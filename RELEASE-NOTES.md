# Test release

AGS Spellchecker is an offline editor plugin for Adventure Game Studio. This package adds a blue mug/ABC/checkmark icon, embedded at multiple sizes for the AGS project tree and docked tab.

Download `AGS-Spellchecker-plugin.zip`, close AGS, copy its DLL beside `AGSEditor.exe`, and restart AGS. Open **Spellchecker > Open AGS Spellchecker**.

Use a copy of your game for testing. Applying corrections automatically saves the entire AGS project, including pending edits. Backups and undo records are stored in the game folder.

Built against AGS 3.6.1. Compilation, assembly/icon loading and panel initialization passed. End-to-end saving, undo and source navigation in a loaded AGS game remain unverified. The checking behavior is unchanged by the icon update.
